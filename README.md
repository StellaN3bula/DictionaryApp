# 📚 Dictionary App (C#)

A simple console application to manage an English–German dictionary. Beginner project -learning by doing 💻
________________________________________
🇩🇪 German version: see README_DE.md
________________________________________
# 🚀 Features

•	📖 Display all words 

•	➕ Add new word pairs 

•	❌ Delete words 

•	🔍 Search words (English ↔ German) 

•	💾 Save data as JSON file 

•	📂 Manage multiple dictionaries 

________________________________________
# 🛠️ Technologies

•	C# 

•	.NET 

•	JSON (System.Text.Json) 

•	File handling (File, Directory) 

________________________________________
# 🎯 Project Goal

This project was created to learn:

•	working with classes and objects 

•	handling file storage with JSON 

•	building a console-based user interface 

•	structuring logic and program flow 

________________________________________
# 🧠 What I Learned

•	JSON does not save automatically → File.WriteAllText() is required 

•	Loading data with JsonSerializer.Deserialize() 

•	Using Dictionary<string, string> 

•	Proper use of loops and break 

•	Error handling with try / catch 

•	Validating user input (string.IsNullOrWhiteSpace)
