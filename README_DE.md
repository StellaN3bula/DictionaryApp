# 📚 Wörterbuch App (C#)
Ein einfaches Konsolenprogramm zum Verwalten eines Englisch-Deutsch-Wörterbuchs.
________________________________________
# 🚀 Features
•	📖 Wörter anzeigen

•	➕ Wörter hinzufügen 

•	❌ Wörter löschen 

•	🔍 Wörter suchen (Englisch ↔ Deutsch) 

•	💾 Speichern als JSON-Datei 

•	📂 Mehrere Wörterbücher verwalten 
________________________________________
# 🛠️ Technologien

•	C# 

•	.NET 

•	JSON (System.Text.Json) 

•	Dateioperationen (File, Directory) 

________________________________________
# 🎯 Ziel des Projekts

Dieses Projekt wurde erstellt, um:

•	den Umgang mit Klassen und Objekten zu lernen 

•	Dateispeicherung (JSON) zu verstehen 

•	Benutzerinteraktion über die Konsole umzusetzen 

•	eigene Logik und Programmstruktur zu üben 

________________________________________
# 🧠 Was ich gelernt habe

•	JSON speichert nicht automatisch → File.WriteAllText() nötig 

•	Laden mit JsonSerializer.Deserialize() 

•	Arbeiten mit Dictionary<string, string> 

•	Schleifen und break richtig einsetzen 

•	Fehlerbehandlung mit try / catch 

•	Benutzerinput absichern (string.IsNullOrWhiteSpace) 

________________________________________

Der Code ist bewusst nicht perfekt optimiert, da dieses Projekt Teil meines Lernprozesses ist.
Ziel war es, die Grundlagen selbst zu verstehen und umzusetzen.
